### Byte: AI-Driven Salesforce Chatbot Enhancement
Internship Project | TaskUs | Summer 2024

### Overview
Byte is an AI-powered Salesforce chatbot designed to streamline sales processes by automating critical tasks and providing predictive insights. During my internship at TaskUs, I engineered enhancements to Byte using custom Apex classes and integrated Python-based AI models for advanced predictive capabilities. Due to confidentiality agreements, this repository only includes a subset of non-sensitive components to demonstrate the project’s core functionality.

### 🚀 Project Highlights
# 1. AI-Powered Workflow Automation
Developed intelligent workflows to create, update, and close Opportunities and Cases autonomously.
Implemented dynamic data fetching and modification via Apex REST APIs, enabling real-time updates across Salesforce objects.
# 2. Predictive Analytics with AI Models
Integrated HuggingFace Transformers with Python APIs using Flask to provide semantic parsing and opportunity scoring models.
Leveraged quantized inference and multi-threaded processing to reduce API latency by 15%, while supporting 350+ concurrent queries.
# 3. Custom Apex Actions for Salesforce Automation
Engineered 9+ custom Apex classes to extend Byte’s functionality for managing records, triggering alerts, and enhancing reporting.
Implemented asynchronous batch processing with Queueable Apex and Future Methods to ensure high system availability.
### 🔍 Technical Stack
Backend: Python, Flask, SQLAlchemy
AI Models: HuggingFace Transformers (BERT for semantic parsing)
Databases: PostgreSQL for data storage and pipeline integration
Salesforce Development: Apex, SOQL, REST APIs, Salesforce Objects
Performance Optimization: Quantization, Multi-threading, Batch Processing
### 📊 Key Features
✅ Opportunity & Case Management
Create/Update Opportunities: Dynamically manage opportunities with essential details (name, amount, close date).
Close Opportunities: Automatically update opportunity status and related fields.
Case Management: Create and update cases with intelligent input processing.
📈 Predictive Insights & Data Analytics
Opportunity Probability Modeling: Predict closing probabilities with machine learning models.
Advanced Data Insights: Provide sales teams with decision-enhancing insights using statistical metrics.
🔁 Real-Time Data Handling & API Integration
Salesforce Sync: Seamlessly fetch and modify Salesforce data using SOQL queries.
API Integration: Exposed REST endpoints for Flask-Python services, ensuring data consistency and minimal latency.
